
# Monitoramento de Níveis de Água

## Descrição
Projeto desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório.

## Objetivo
Exibir mensagens coloridas conforme o nível de água.

## Tecnologias utilizadas
- Python
- Colorama

## Níveis do reservatório
- Nível 1: Muito baixo - Vermelho
- Nível 2: Baixo - Amarelo
- Nível 3: Médio - Verde
- Nível 4: Alto - Ciano
- Nível 5: Muito alto - Azul

## Como executar
1. Instale o Colorama com:
   python -m pip install colorama
2. Execute:
   python monitoramento_agua.py
